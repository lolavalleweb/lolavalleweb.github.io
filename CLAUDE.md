# Contexto del proyecto

Web estática de lolavalle.com (GitHub Pages). El contexto, las reglas para la IA y el reparto de pendientes se
mantienen fuera de este repo, en el Gitea de `casa`: las reglas de trabajo en `claude-config` y el inventario
(servicios, dominio, cuentas) en `inventario-red`:

@../casa/claude-config/docs/web-lolavalle.md
@../casa/inventario-red/software/web-lolavalle.md

Si el contexto anterior no se ve, la importación falla: leer a mano `docs/web-lolavalle.md` de `claude-config` y `software/web-lolavalle.md` de `inventario-red` y
avisar al usuario. Este fichero es público: no añadir aquí nada de infraestructura, cuentas ni DNS.
